 :r1 Porovnává čísla s tolerancí, a může tak zohlednit drobné odchylky způsobené omezenou přesností výpočtu.
 :r2 Převede obě čísla na text a porovná jen jejich vytištěnou podobu.
 :r3 Zaokrouhlí obě čísla na celá čísla a přepíše původní objekty.
 :r4 Nahradí případné chybějící hodnoty nulami před přesným porovnáním.
:r1 ok Čísla typu double mají konečnou přesnost a běžný výpis může malé rozdíly skrýt. Near() porovnává hodnoty s tolerancí, místo aby vyžadovala přesnou rovnost.
:r2 0 Near() porovnává číselné hodnoty. Shodný zaokrouhlený výpis sám o sobě přesnou rovnost nezaručuje.
:r3 0 Near() vrací výsledek porovnání. Nezaokrouhluje vstupy na celá čísla ani nepřepisuje původní objekty.
:r4 0 Near() chybějící hodnoty nulami nenahrazuje. Slouží k porovnání blízkosti čísel, nikoli k doplňování dat.

::Logické hodnoty a podíl dokončení::Ve fiktivním souboru pěti účastníků je dokonceno <- c(TRUE, TRUE, FALSE, NA, TRUE). Jak interpretujete mean(dokonceno, na.rm = TRUE)?
 :r1 Výsledek 0.6 znamená, že úkol dokončilo 60 % všech pěti osob, a chybějící stav byl zahrnut jako FALSE.
 :r2 Výsledek 3 znamená, že úkol dokončily tři osoby.
 :r3 Výsledek NA znamená, že kvůli jedné chybějící hodnotě nelze spočítat ani podíl mezi osobami se známým stavem.
 :r4 Výsledek 0.75 znamená, že úkol dokončilo 75 % ze čtyř osob se známým stavem.
:r1 0 Na.rm = TRUE chybějící stav při výpočtu vynechá, nenahrazuje jej hodnotou FALSE. Jmenovatelem jsou čtyři známé stavy.
:r2 0 Počet tří dokončení by vrátilo sum(dokonceno, na.rm = TRUE). Mean() jej dělí počtem dostupných hodnot a vrací podíl.
:r3 0 Díky na.rm = TRUE se průměr spočítá z dostupných hodnot. Bez tohoto nastavení by výsledkem skutečně bylo NA.
:r4 ok TRUE se při výpočtu počítá jako 1 a FALSE jako 0. Tři dokončení ze čtyř známých stavů dávají 0.75. O stavu zbývající osoby tento výsledek nic nedoplňuje.
